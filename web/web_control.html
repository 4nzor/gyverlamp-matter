Готов к загрузке прошивки…
Команда OTA отправляется дважды (как в прошивке Gyver). Окно обновления ≈ 5 минут. Прокси вызывает espota.py / HTTP :8266. В режиме WebSocket команда OTA идёт на лампу напрямую, загрузка .bin — всё ещё через прокси.
